# Виртуальные обнимашки

Анимация из символов в одном HTML-файле. Синяя фигурка запечатывает письмо и отправляет его, розовая ловит конверт и открывает, а оттуда выпрыгивает синяя и обнимает её. Фигурки, конверт и луна нарисованы только буквами, цифрами и знаками. По трём быстрым кликам пара рассыпается на символы, которые собираются в признание: «Даже если нас разделяют километры, мне всё равно хочется каждый день находить дорогу к тебе».

Без сборки, без зависимостей и без сервера. Достаточно открыть `index.html` в браузере.

## Запуск

Локально: скачайте репозиторий и откройте `index.html` двойным кликом.

### Выложить в интернет

**GitHub Pages** (проще всего, если код уже на GitHub; репозиторий должен быть публичным на бесплатном тарифе):

1. Откройте **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
3. Через минуту страница появится по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

**Cloudflare Pages** (быстрый CDN, без ограничений по трафику): **Workers & Pages → Create → Pages → Connect to Git**, выберите репозиторий. Команду сборки оставьте пустой, папку вывода укажите `/`. Вариант без Git: Direct Upload и перетащить папку.

**Neocities** (без Git и без сборки): зарегистрируйтесь, перетащите `index.html` в панель сайта. Адрес будет `https://<имя>.neocities.org`.

## Управление

| Действие | Результат |
|---|---|
| Три быстрых клика или тапа по сцене | пара рассыпается на символы и собирается в текст |
| Ещё три клика | текст рассыпается и фигурки возвращаются на то же место сюжета |
| Кнопка «Заново» | начать анимацию сначала |
| Кнопка «Пауза» | остановить и продолжить |
| Ползунок | перемотка по времени |
| Список шагов под сценой | перейти к нужной сцене |

Клики считаются тройными, если между ними не больше полсекунды и курсор почти не двигался. Текст появляется в любой момент и остаётся, пока по нему не кликнут снова. Он состоит из четырёх слайдов, они сменяются сами.

## Сюжет по секундам

| Время, с | Что происходит |
|---|---|
| 0–2 | синий запечатывает письмо |
| 2–3,2 | прячется в конверт |
| 3,2–5,2 | письмо летит к розовой |
| 5,2–8,2 | розовая ловит и открывает конверт |
| 8,2–9,8 | синий выпрыгивает наружу |
| 9,8+ | приземление, шаги навстречу, объятие и надпись «ОБНИМАШКА!» |

## Как это устроено

Всё считается в браузере на Canvas 2D, без WebGL и без изображений.

1. **Фигурки.** Голова, туловище, ноги, руки с локтями и кисти собраны из капсул (отрезков с круглыми концами). Конверт состоит из треугольников и линий.
2. **Растеризация.** Примитивы проецируются на сетку символьных ячеек (пропорция ячейки 2:1) и сравниваются по глубине, в ячейке остаётся ближайшая точка.
3. **Свет.** Два источника: неподвижный и движущийся. Считаются диффузный свет, блик и подсветка по краю.
4. **Символы.** Яркость переводится в символ из шкалы `.,:;!i1tlIfjLCOQ0#8%@` и в один из 32 оттенков материала: синий, розовый, бумага и золото, красный, луна, кремовый для лиц.
5. **Время.** Кадр строится чистой функцией `build(t)` от времени, поэтому ползунок и кнопки шагов работают без накопления состояния.
6. **Рассыпание.** Берётся снимок освещённых ячеек. Они разлетаются, затем по кривым собираются в ячейки текста. Текст рисуется крупным шрифтом на скрытом холсте и режется на блоки 4×8 пикселей, каждый блок становится символом.

## Адаптация под телефон

- На экранах уже 620 px сетка 84 колонки вместо 130, а строки текста переносятся по 8 букв.
- На устройствах с касанием анимация ограничена 30 кадрами в секунду.
- Учтены вырезы и безопасные зоны (`viewport-fit=cover`, `safe-area-inset`).
- Страница не перерисовывается из-за сворачивания адресной строки Safari.
- При включённом `prefers-reduced-motion` анимация стоит на финальной сцене.

## Настройка

Всё находится в скрипте внутри `index.html`.

| Что поменять | Где |
|---|---|
| Текст признания | функция `buildSlides()`, массив строк слайдов |
| Надпись над обнимашками | функция `buildBanner()` |
| Цвета фигурок, письма, луны | объект `PALS` |
| Число колонок сетки | `COLS` в функции `setup()` (больше значит мельче, но тяжелее) |
| Шкала символов | `RAMP` |
| Сколько держится слайд текста | `HOLD`, секунды |
| Длительность рассыпания и сбора | `SDUR`, `GDUR` |
| Общая длительность | `LOOP`, `END` |

Если меняете текст, учтите перенос: на десктопе строка режется по 12 символов, на телефоне по 8.

## Технологии

- HTML, CSS, JavaScript без сборки и без библиотек.
- Шрифты [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono) и [Bodoni Moda](https://fonts.google.com/specimen/Bodoni+Moda) подключаются с Google Fonts. Без интернета страница работает на системных шрифтах, нужен только моноширинный.

## Браузеры

Современные Chrome, Safari, Firefox и Edge. Нужны Canvas 2D и Pointer Events. Проверено в Chromium, включая эмуляцию iPhone; на настоящем iPhone не тестировалось.
